# Components
- Dark mode: navigation screens use tokens only; dark values live in the `.dark` block of `src/styles.css` and `.dark` sits on `<html>` (set before paint by the head boot script in `src/lib/theme.ts`). Lesson pages (`isLightOnlyPath`) are forced light until their dark design exists, except the warm-up screen (`lesson/mcq/WarmupShell.tsx` toggles `.dark` itself). Always-white surfaces use `*-fixed` tokens; chapter cards use `--ch-NN`/`--ch-NN-ink`; contrast is enforced by `src/test/dark-contrast.test.ts`. Why: one theme switch with no flash, and AA cannot regress.
- Page widths come only from the shared utilities in `src/styles.css`: `topbar-row` (top bar inner row), `nav-container` (Home, chapters, quests), `lesson-container` (intro and lesson steps), `page-top` (gap below the bar); every page uses the one `TopBar`/`BottomTabs` from `HomeParts.tsx`. Why: one set of width and spacing rules on every page.
- Game sounds: `src/lib/sound.ts` only (used by components) — the balafon set (Web Audio, no files, one master gain, named sounds, one at a time, starts after first tap, off switch in FitilaShell). Why: one place to tune or replace sounds.

- Leaderboard: a side tab on every lesson step (`src/components/leaderboard/LeaderboardTab.tsx`, rendered from `LessonScreen.tsx`, never on Ask Fiti or the map) showing only her own progress; pure counts in `src/server/home/progress.ts` (tested), data in `progress.server.ts` with the Restart cutoff, Fiti lines `progress_*`; `/leaderboard` is redirect-only and the old class-ranking code is unused. Why: students see their own progress, never a ranking of minors.
- Edge tabs (Leaderboard on lesson steps, Chat history on Ask Fiti only, left of the content) share `src/components/side-tab/SideTab.tsx`; Chat history lists all her chats (also from before a Restart) with a message from her (`src/server/home/conversations.ts`, tested) and opens one via `openConversationFn`, which re-checks ownership, then fills the `["home-history"]` cache. Why: one tab look, and a chat can only be reopened by its owner.
- App-open splash: `src/components/splash/Splash.tsx`, mounted once in `__root.tsx` over the page while it loads (timings in `src/shared/splash-plan.ts`, tested); routing/auth redirects run underneath; the full version plays on every page load, never on in-app navigation. Why: the splash never delays the app and deep links keep working.
