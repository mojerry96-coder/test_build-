# Assets

- `mascot.png`: a reusable transparent parrot asset generated for this replication package, based on the parrot in the Line Lab reference. It is a new matched rendering rather than an exact crop. Keep the original aspect ratio, use `object-fit: contain` and do not enlarge it to dominate the task.
- `SNPro-Regular.ttf`, `SNPro-Bold.ttf`: SN Pro font files obtained from Google Fonts; see `snpro-OFL.txt`.
- `PatrickHand.ttf`: Patrick Hand font from Google Fonts; see `patrickhand-OFL.txt`.
- The three `references/*.png` files are the original screen concepts generated in the previous turn. They are visual references; the actual graph is rendered mathematically in SVG.

Mascot generation direction: one friendly full-body African grey parrot, grey layered feathers, round black spectacles, black beak, red tail, standing in three-quarter view, no text, no UI, transparent background.

Font project sources:
- https://github.com/google/fonts/tree/main/ofl/snpro
- https://github.com/google/fonts/tree/main/ofl/patrickhand
